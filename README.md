# استوديو ألوان الركن — عالم الكوفي

صفحة ثلاثية الأبعاد يختار فيها العميل ألوان ركن القهوة (الجسم والسطح) ويشوف الشكل مباشرة، ثم يطلب السعر عبر واتساب.

## طريقة النشر على GitHub Pages
1. أنشئ مستودع جديد (Repository) في GitHub، مثلاً `coffee-corner-studio`، واجعله **Public**.
2. اضغط **Add file ← Upload files** وارفع **كل محتوى هذا المجلد** (الملف `index.html` والمجلدات) — مو المجلد نفسه، محتواه.
3. اضغط **Commit changes**.
4. روح **Settings ← Pages**، وتحت **Source** اختر `Deploy from a branch`، الفرع `main` والمجلد `/ (root)`، ثم **Save**.
5. بعد دقيقة أو دقيقتين يظهر الرابط: `https://اسم-حسابك.github.io/coffee-corner-studio/`

## محتويات المجلد
| المسار | المحتوى |
|---|---|
| `index.html` | الصفحة كاملة (التصميم + محرك العرض ثلاثي الأبعاد) |
| `brand/` | شعارات عالم الكوفي / متين |
| `prod/` | صور المنتجات (الأركان) |
| `tex1/` `tex2/` | صور خامات الألوان المستخدمة على المجسم |
| `thumb1/` `thumb2/` | صور مصغرة لدوائر الألوان |

> ملاحظة: افتح الصفحة من رابط GitHub Pages وليس بالضغط المزدوج على الملف من جهازك، لأن المتصفح يمنع تحميل الخامات من الملفات المحلية.
